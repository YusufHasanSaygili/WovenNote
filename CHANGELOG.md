# Changelog

All notable changes to WovenNote are documented here.

## [0.1.7] - 2026-08-03

### Added

- Local-first rich note editing, search, tags, board layouts, version history, export, and full-library backups
- Image, GIF, PDF, local video, file, and YouTube content blocks
- Optional note-aware OpenAI chat and inline AI actions
- Turkish and English interfaces with light, dark, and system themes
- Windows x64 NSIS installer and packaged-application smoke coverage

### Improved

- Responsive note cards and scrollable card menus at constrained heights
- Independent image and PDF insert controls
- Movable linked and local video blocks
- Image size control contrast and bilingual AI settings
- <kbd>Ctrl</kbd> + mouse-wheel zoom

### Security

- Sandboxed renderer with context isolation, disabled Node integration, validated IPC, protected attachment paths, and encrypted optional API-key storage
